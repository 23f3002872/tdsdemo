# TDS GA2 Project Showcase

This repository hosts a simple GitHub Pages website for the TDS GA2 project.

## About This Repository

The primary purpose of this repository is to serve as a demonstration and testing ground for GitHub Actions and workflows. It contains a basic `index.html` file that is published as a GitHub Page.

## Usage

The live page can be viewed at the GitHub Pages URL associated with this repository.

## Development

This repository is configured with GitHub Actions to automate certain tasks. The primary content of the page is located in `index.html`.
